## Control Extractor Output Schema

### Extractor: `control_extractor_unified.py` and `control_extractor_combined.py`

**Output Format:** JSON array of control objects

```python
{
    # Core Control Identification
    "control_id": str,                    # Control identifier (e.g., "CTL-001", "CC1.2")
    "control_seq": int,                   # Sequential number within report
    "control_line_ref": int,              # Line number in source PDF
    "control_page_refs": [int],           # Array of page numbers where control appears
    
    # Control Description & Test
    "control_desc": str,                  # Control description/objective
    "control_tests": [str],               # ⚠️ ARRAY - Test procedures (converted to text before insert)
    "control_test_results": [str],        # ⚠️ ARRAY - Test results (converted to text before insert)
    
    # Deviation Information
    "has_deviation": bool,                # Whether control has a deviation
    "deviation_desc": str,                # Deviation description (if has_deviation=true)
    
    # GPT Analysis
    "control_gpt_opinion": str,           # GPT's assessment of control quality
    "control_gpt_reasoning": str,         # Reasoning for GPT opinion
    "control_confidence": float,          # GPT confidence score (0.0-1.0)
    "confidence_calc": str,               # Explanation of confidence calculation
    
    # Multi-Factor Verification (5-Factor Confidence System)
    "verification_status": str,           # "verified" or "pending"
    "verification_metadata": {
        "factor_scores": {
            "gpt_confidence": float,      # 0.0-1.0
            "pattern_confidence": float,  # Pattern library match score
            "structure_score": float,     # Completeness of fields
            "framework_score": float,     # Quality of framework mappings
            "deviation_score": float      # Consistency of deviation flag
        },
        "final_confidence": float,        # Weighted combination of factors
        "verified_at": str,               # ISO timestamp
        "verified_by": str,               # "system"
        "method": str                     # "5-factor" or "legacy-2-factor"
    },
    "pattern_confidence": float,          # Pattern library score (0.0-1.0)
    "final_confidence": float,            # Overall confidence (0.0-1.0)
    
    # Framework Mappings (Multi-Framework Support)
    "framework_mappings": {
        "TSC": [{                         # Trust Services Criteria
            "criterion_id": str,          # e.g., "CC1.2"
            "criterion_name": str,
            "confidence": float,
            "similarity": float,
            "reasoning": str
        }],
        "COSO": [{...}],                  # COSO framework
        "FINANCIAL_ASSERTIONS": [{...}],  # SOC 1 assertions
        # Additional frameworks as needed
    },
    "primary_framework": str,             # Framework with highest confidence
    "primary_criterion_id": str,          # Best matching criterion ID
    "primary_confidence": float,          # Confidence of best match
    
    # SOC 1 Specific Fields
    "financial_assertions": [{            # For SOC 1 Type 2 reports
        "id": str,                        # e.g., "EO1"
        "name": str,                      # e.g., "Existence/Occurrence"
        "confidence": float,
        "reasoning": str
    }],
    "framework_category": str,            # "SOC1", "SOC2", "BOTH", "AMBIGUOUS"
    
    # Control Status & Merging
    "control_status": str,                # "active", "merged", etc.
    "merged_to_control_id": str,          # ID if this control was merged
    
    # Metadata
    "scan_id": int,                       # Foreign key to scan table
    "continuation": bool                  # True if multi-page continuation
}
```

### Field Transformations Required

⚠️ **CRITICAL:** Before INSERT, these fields must be transformed:

1. **`control_tests` (array) → `control_test` (text)**
   - Join array elements with newlines or delimiters
   - Example: `["Test 1", "Test 2"]` → `"Test 1\n\nTest 2"`

2. **`control_test_results` (array) → `control_test_results` (text)**
   - Join array elements with newlines
   - Example: `["Result 1", "Result 2"]` → `"Result 1\n\nResult 2"`

### Fields NOT in INSERT Mapping (Set Later)

These fields are NOT output by extractors and should NOT be in TABLE_FIELD_MAP:
- `annotation` - Set by manual user annotations
- `analyst_notes` - Set by analyst manual notes
- `edit_log` - Set by edit tracking system
- `deviation_summary` - Generated by deviation router
- `merge_history` - Populated by merge service
- `is_duplicate_instance`, `duplicate_group_id`, `instance_differentiator` - Set by duplicate management
- `updated_at`, `updated_by_user_id` - Set by audit system

## CUEC Extractor Output Schema

### Extractor: `cuec_extractor.py`

**Output Format:** JSON array of CUEC objects

```python
{
    # Core CUEC Identification
    "cuec_seq": int,                      # Sequential number within report
    "cuec_description": str,              # CUEC description text
    "cuec_line_ref": int,                 # Line number in source PDF
    "cuec_page_refs": [int],              # Array of page numbers
    
    # Confidence Scoring
    "cuec_confidence": float,             # Overall confidence (0.0-1.0)
    "cuec_gpt_opinion": str,              # "likely_cuec", "unlikely_cuec", etc.
    "cuec_distance_from_cuec_keywords": int,  # Distance from section headers
    "cuec_gpt_reasoning": str,            # Explanation of GPT decision
    "cuec_justification": str,            # Why this is/isn't a CUEC
    "cuec_confidence_justification": str, # Detailed confidence breakdown
    
    # Framework Mappings
    "framework_mappings": {
        "TSC": [{...}],
        "COSO": [{...}]
    },
    "primary_framework": str,
    "primary_criterion_id": str,
    "primary_confidence": float,
    
    # Risk Assessment
    "control_strength": str,              # "High", "Medium", "Low"
    
    # Metadata
    "annotation": str,                    # Optional annotation from extractor
    "scan_id": int
}
```

### Fields NOT in Extractor Output

- `analyst_notes` - Manually added after extraction
- `edit_log` - Set by edit tracking system

## Subservice Organization Extractor Output Schema

### Extractor: `subservice_orgs.py`

**Output Format:** JSON array of subservice organization objects

```python
{
    # Core Identification
    "name": str,                          # Third-party organization name
    "third_party_description": str,       # What services they provide
    "third_party_page_ref": str,          # Page reference (may be text)
    
    # Confidence Scoring
    "confidence": float,                  # Overall confidence (0.0-1.0)
    "third_party_confidence": float,      # Detailed confidence score
    "confidence_justification": [str],    # Array of reasons for score
    
    # Context Analysis
    "distance_from_so_keywords": float,   # Distance from "subservice org" keywords
    "likely_so": str,                     # "Yes", "No", or "Unknown"
    "common_so": str,                     # "Yes" if in common provider list
    "source_context": str,                # Surrounding text context
    
    # Controls
    "third_party_controls": [{            # Array of controls for this provider
        "third_party_control_seq": int,
        "third_party_control_id": str,
        "third_party_control_desc": str
    }],
    
    # Metadata
    "scan_id": int,
    "annotation": str,                    # Optional annotation
    "analyst_notes": str,                 # Optional notes
    "edit_log": str                       # Optional edit log
}
```

**Note:** All fields are included in INSERT mapping (15 of 16 fields - all except 'id')

## Field Type Mappings

### Python Type → PostgreSQL Type

| Python Type | PostgreSQL Type | Notes |
|-------------|-----------------|-------|
| `str` | `text` or `varchar(N)` | Use `text` for unlimited length |
| `int` | `integer` | Standard 4-byte integer |
| `float` | `double precision` | 8-byte floating point |
| `bool` | `boolean` | True/False |
| `list` | `json` | Stored as JSON array |
| `dict` | `json` | Stored as JSON object |
| `datetime` | `timestamp` | ISO format string converted to timestamp |

### JSON Structure Storage

Fields containing complex nested structures (like `framework_mappings`, `verification_metadata`, etc.) are stored as JSON in PostgreSQL and accessed as Python dictionaries through SQLAlchemy.

## Validation Rules

### Required Fields (must not be null/empty)

**Control:**
- `control_id` - Must have an identifier
- `control_desc` - Must have description
- `scan_id` - Must link to a scan

**CUEC:**
- `cuec_description` - Must have description
- `scan_id` - Must link to a scan

**Subservice Org:**
- `name` - Must have organization name
- `scan_id` - Must link to a scan

**Company:**
- `name` - Must have company name
- `scan_id` - Must link to a scan

**Product:**
- `name` - Must have product name
- `scan_id` - Must link to a scan

## Usage Notes

### When Adding New Extractor Fields

1. **Update this document** with new field schema
2. **Add to models.py** - Define column in SQLAlchemy model
3. **Create migration** - Use Alembic to add database column
4. **Update TABLE_FIELD_MAP** - Add to config.py INSERT mapping
5. **Update extractor** - Ensure field is populated
6. **Run validation test** - `pytest test_schema_validation.py`
7. **Update frontend** - If field is user-facing

### When Removing Fields

1. **Remove from TABLE_FIELD_MAP** first
2. **Create migration** to drop database column
3. **Remove from models.py**
4. **Update this document**
5. **Run validation test**
