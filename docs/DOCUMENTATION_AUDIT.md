## 📝 Notes

### Why Archive Instead of Delete?
- Historical context for understanding decisions
- Reference for similar future work
- Audit trail for project evolution
- May contain useful implementation notes

### When to Delete vs Archive?
**Delete if:**
- Redundant (info exists elsewhere)
- Purely progress tracking (no final conclusions)
- Outdated and misleading

**Archive if:**
- Contains implementation details
- Documents completed work
- May be referenced in the future
- Has historical value

### Maintenance Going Forward
- Archive "COMPLETE" docs 30 days after completion
- Archive sprint/phase docs when next sprint/phase starts
- Delete progress/status docs when final summary exists
- Keep INDEX.md updated with archive references
