# Deviations Tab

## Overview

The Deviations Tab provides a focused view of all controls with exceptions or deviations, enabling efficient review and management of audit findings.

## Purpose

- Quick access to controls that failed testing
- Centralized deviation management
- Exception tracking and documentation
- Audit follow-up planning

## Features

### Filtered View
Shows only controls where `has_deviation = true`:
- Automatically filtered
- No manual filtering needed
- Updates in real-time

### Deviation Information
Each row displays:
- **Control ID**: Reference identifier
- **Control Description**: What was tested
- **Deviation Description**: Details of the exception
- **Test Results**: Specific findings
- **Pages**: Source page references

### Inline Editing
Edit deviation details directly:
1. Click deviation_desc cell
2. Update exception details
3. Auto-saves on blur
4. Maintains audit trail

### Severity Classification
Flag deviation severity:
- **Critical**: High-risk exceptions
- **Moderate**: Medium-risk findings
- **Low**: Minor exceptions
- Custom tags available

## Common Deviation Types

### Testing Exceptions
- Sample size issues
- Missing documentation
- Incomplete evidence

### Design Deficiencies
- Control not properly designed
- Gaps in control logic
- Inadequate coverage

### Operating Effectiveness
- Control not operating as designed
- Inconsistent application
- Timing issues

### Scope Limitations
- Unable to test
- Client-imposed restrictions
- Data not available

3. **Document**: Update deviation_desc

- Batch severity assignment
